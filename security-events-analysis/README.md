# HW9 — Security Events Analysis

Анализ событий информационной безопасности на основе данных в формате JSON.

Работа выполнена в рамках домашнего задания по курсу Python  
(репозиторий `HSE-Python`, сдача через отдельную ветку).

---

## 📌 Описание задания

В рамках домашнего задания выполнены следующие шаги:

1. Загрузка данных из JSON-файла в DataFrame с использованием библиотеки Pandas  
2. Анализ распределения событий информационной безопасности по типам  
   (по полю `signature`)  
3. Вывод результатов анализа в консоль  
4. Визуализация распределения типов событий с помощью Matplotlib

## ▶️ Запуск проекта

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Запустите анализ:

```bash
python analysis.py
```

После запуска:

в консоль будет выведена информация о количестве событий, сигнатурах и результатах анализа;

откроется окно с графиком распределения событий информационной безопасности по типам.
